# viz_studio — Toronto Hidden Infrastructure

An interactive Dash dashboard exploring Toronto's buried waterways, sewer network, flood history, and historical cartography. Two pages: a year-slider map and a historical maps viewer.

## Pages

### Interactive Map (`tab-map`)
Year slider from 1802–2022 controls all layers simultaneously.

| Layer | Source | Details |
|---|---|---|
| Ward basement floods | Toronto Open Data | Basement flood service requests 2005–2022, by ward |
| Neighbourhood flood reports | Toronto Open Data | Reported flood events 2013–2017 by neighbourhood |
| Lost rivers — still flowing | DOI 10.5683/SP2/TSJSQZ | Cyan: rivers still on surface in the selected year |
| Lost rivers — already buried | DOI 10.5683/SP2/TSJSQZ | Purple: rivers channelled underground before selected year |
| Trunk sewers | Toronto Open Data | 3,200 major sewer mains with install year, material, diameter |
| Precipitation annotation | Open-Meteo ERA5 | Annual total, rain/snow split, heavy-rain days (>25 mm) |

### Historical Maps (`tab-history`)
Slider steps through 8 historical cartographic maps (1818–1889) sourced from the University of Toronto Map & Data Library. Each map is paired with a description of which rivers and creeks were buried in that period.

| Year | Map | Key burial |
|---|---|---|
| 1818 | Phillpotts — Plan of York | All waterways still surface |
| 1842 | Cane Topographical Map | Garrison Creek mouth (harbour infill) |
| 1851 | Fleming Topographical Plan | Lower Taddle Creek culverted (first burial) |
| 1858 | Maclear's Sewer Plan | Taddle Creek Queen→lake, Park Creek |
| 1882 | McMurrich Parks Plan | Taddle Creek (campus), Garrison Creek south of King |
| 1888 | Don River Straightening | 12 Don tributary streams, lower Don meanders |
| 1888 | Proposed Interceptor Sewers | Garrison Creek full course (brick tunnel) |
| 1889 | Intercepting Sewers & Outfall | Castle Frank Creek, Mud Creek, Brewery Creek |

## Setup

```bash
pip install -r requirements.txt
```

## Data

### Option A — download via API (recommended)
```bash
python src/eda/fetch_data.py
```
Downloads all datasets automatically from Toronto Open Data (CKAN API), Borealis Dataverse, and Open-Meteo ERA5. Lost rivers require manual download if the Dataverse API is unavailable (instructions printed to console).

### Option B — manual placement
Place raw data under `data/raw/`:

```
data/raw/
├── sewers/
│   └── Trunk Sewer - 4326.geojson
├── rivers/
│   └── doi-10.5683-sp2-tsjsqz/LostRiversData/Webmaps_data/
│       └── LR_Toronto_Comp_WAS_geojson/
│           └── BI_Lost_Rivers_20170705_WAMS_qgis.geojson
├── floods/
│   ├── basement-flooding-by-ward.xlsx
│   ├── city-wards-4326.geojson
│   └── flood-reporting/
│       └── *.shp                        ← any shapefile in this dir
└── precipitation/
    ├── toronto_daily_precip.csv         ← generated by fetch_data.py
    └── toronto_annual_precip.csv
```

**Data sources:**
- [City of Toronto Open Data](https://open.toronto.ca) — sewers, ward boundaries, flood reports, basement flooding
- [Lost Rivers of Toronto — Borealis Dataverse](https://doi.org/10.5683/SP2/TSJSQZ) — buried waterway geometries
- [Open-Meteo ERA5](https://open-meteo.com) — daily precipitation 1960–2022, no API key required
- [U of T Map & Data Library](http://maps.library.utoronto.ca) — historical map images (1818–1889)

## Project context

This project explores the relationship between Toronto's buried waterways, sewer infrastructure, and basement flooding patterns. The historical maps page shows how systematically every creek within the city was channelled underground between 1851 and 1895 — and the interactive map lets you correlate those buried paths with modern flood-prone wards.
